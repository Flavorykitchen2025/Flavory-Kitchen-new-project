
# FlavoryKitchen.com

Luxury catering website for Flavory Kitchen & Al Imad Sweets.

## Features
- Responsive modern design
- Catering services
- Arabic sweets menu
- Buffet image gallery
- Testimonials
- Contact & booking form
- Automatic email notifications

## Contact Form Email Setup

This website uses FormSubmit:
https://formsubmit.co

All contact form submissions are sent to:
ali_zd@live.com

IMPORTANT:
After deploying the website:
1. Submit ONE test form
2. Check your email
3. Click Activate

After activation, all inquiries will arrive directly to your inbox.

## GitHub Upload Commands

```bash
git init
git add .
git commit -m "Initial Flavory Kitchen website"
git branch -M main
git remote add origin https://github.com/YOURUSERNAME/flavorykitchen.com.git
git push -u origin main
```

## GitHub Pages

Enable:
Settings → Pages → Deploy from branch → main
